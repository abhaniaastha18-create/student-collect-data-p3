Collection manipulation means performing operations on the elements stored in a collection.
Common Collection Manipulation Operations
Operation	Python Method	Example
Add	append()	list.append(10)
Insert	insert()	list.insert(1, 20)
Remove	remove()	list.remove(10)
Delete	pop()	list.pop()
Sort	sort()	list.sort()
Reverse	reverse()	list.reverse()
Search	in	10 in list
Count	count()	list.count(10)
Length	len()	len(list)
Clear	clear()	list.clear()
Collection manipulation means performing different operations on collections of data in Python, such as adding, removing, updating, searching, sorting, and accessing elements.

Python provides several built-in collection types:

List
Tuple
Set
Dictionary

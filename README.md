Common Collection Manipulation Operations
Operation	Python Method	Example

-Delete	pop()	list.pop()

Collection manipulation means performing different operations on collections of data in Python, such as adding, removing, updating, searching, sorting, and accessing elements.

Python provides several built-in collection types:

=List
=Tuple
=Set
=Dictionary


-append() → adds an element
-insert() → inserts an element at a specific position
-remove() → removes a particular element
-pop() → removes an element using its index
-sort() → sorts the list
-reverse() → reverses the list
-clear() → removes all elements

-add() → add an element
-remove() → remove an element
-union() → combines two sets
-intersection() → common elements
-difference() → elements present in one set but not another

-keys() → returns keys
-values() → returns values
-items() → returns key-value pairs
-get() → gets a value
-update() → updates dictionary
